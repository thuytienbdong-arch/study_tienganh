🚀 Đưa web lên mạng miễn phí

Cả ứng dụng nằm trong 1 file index.html, chạy mượt trên mọi thiết bị, tiến độ học được lưu ngay trên máy bạn.

Đưa lên GitHub Pages (1 phút)
  1. Bấm "Tải index.html" bên dưới.
  2. Vào github.com/new, tạo repo vstep-b1-template (Public) rồi upload file.
  3. Settings → Pages → Branch main → Save. Chờ ~30 giây là có link.
📱 Cài như app trên điện thoại
  1. iPhone (Safari): nút Chia sẻ → Thêm vào Màn hình chính.
  2. Android (Chrome): menu ⋮ → Thêm vào màn hình chính.
